# Blood Donation System

"Build a modern, responsive Blood Donation Management web application in React with Tailwind CSS. Use a primary dark red theme (#8B0000). Include a top navigation bar with tabs for 'Find Donors', 'Request Blood', 'Blood Inventory', and 'My Profile'.

1. Create a Donor Profile & Eligibility Setup Screen where a user can enter: Blood Group (A+, A-, B+, B-, AB+, AB-, O+, O-), Body Weight (kg), Last Donation Date, and Availability Toggle (Available/Unavailable). 2. Include a Donor Eligibility Checker card that outputs 'Eligible to Donate' or 'Not Eligible to Donate' based on: Age >= 18, Weight >= 50kg, and Last Donation Date >= 90 days ago."
